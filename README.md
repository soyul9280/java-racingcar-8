# ✅ 기능 구현 목록

## 입력 초기화
- [x] 자동차 이름 입력 안내 문구 출력
- [ ] 자동차 이름 입력
- [x] 시도할 횟수 입력 안내 문구 출력
- [ ] 시도할 횟수 입력

## 자동차 등록
- [ ] 자동차를 등록한다.
- [x] `예외상황`: 자동차 이름이 5자 초과하는 경우
- [x] `예외상황`: 자동차 이름이 `null`인 경우
- [x] `예외상황`: 자동차 이름에 공백이 들어올 경우
- [ ] `예외상황`: 자동차 이름에 `,`가 연속으로 들어오는 경우
- [x] `예외상황`: 자동차 이름에 `,`만 있는 경우
- [x] `예외상황`: 자동차 이름들을 `,`가 아닌 다른 특수문자가 있는 경우
- [x] `예외상황`: 자동차 이름이 `,`로 시작하거나 끝나는 경우


## 경주
- [ ] `예외상황`: 시도 횟수가 0인 경우
- [ ] `예외상황`: 시도 횟수가 null인 경우


- [ ] 랜덤 숫자 뽑기
- [ ] `예외상황`: 랜덤 숫자가 0,9 범위 밖에 있을 경우


- [ ] 자동차 이동
- [ ] `예외상황`: 이동 위치가 int범위 넘어간 경우


- [ ] 이동 결과 비교

## 결과 출력 및 종료

- [ ] 자동차 차수별 결과 메시지 출력
- [ ] 우승자 메시지 출력
