# 설계 구조
- Application : 실행을 관리
- RacingController : 데이터 전달 및 진행(메서드 호출) 역할
- view
    - InputView : 입력
    - OutputView : 출력
- domain
    - Car : `CarName` , `Position` 을 속성으로 가지고 자동차의 역할
    - CarName : `String` 으로 자동차 이름을 속성으로 가짐. 자동차 이름에 대한 검증을 관리
    - Cars : `List<Car>` 를 가지고 있는 일급 컬렉션으로 자동차들을 관리
    - Position : `int` 로 자동차 위치 정보를 속성으로 가짐. 위치에 대한 검증을 관리
    - AttemptNumber : 시도 횟수 역할. 횟수에 대한 검증을 관리
- message
    - ErrorMessage : 에러 메시지를 관리
- Utils : 전역으로 사용될 가능성이 있는 함수들과 입력 검증 모음
